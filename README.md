# Hi, I'm Cristian Marrero

**QA Engineer · Test Automation** · Montevideo, Uruguay

🔎 **Open to QA Automation roles** (remote or Montevideo)

I've spent more than four years testing web, mobile, API, IoT and AI-powered products for global companies, including
**WHOOP** (via OrangeLoops), **Jam City** and **Globant**. These days my focus is test automation: I build UI and API
suites with **Playwright and TypeScript**, and I've also automated regression suites with Selenium WebDriver and Node.js.

I've worked as a QA in agile, remote, cross-functional teams, and here's what I've learned matters most:

- **Tests people trust.** Isolated test data created through the API, web-first assertions, no fixed waits. A red build
  should mean a real problem.
- **Coverage beyond the happy path.** Exploratory testing, edge cases (often with help from AI tools), accessibility
  and performance checks.
- **Bug reports that get fixed.** Clear steps, evidence and impact. I led an accessibility audit at WHOOP that made
  accessibility a standard QA check for every new feature.

## Featured project

### [athena-bank-playwright-tests](https://github.com/Zetyre/athena-bank-playwright-tests)

A Playwright + TypeScript framework for a full-stack banking app (React, Node.js, MongoDB).

- 36 test cases, run 76 times across Chromium, Firefox, WebKit and a browserless API project
- Typed fixtures, page objects, per-test data created through the API, and network mocking for error states
- GitHub Actions pipeline: lint and type checks, one job per browser, a merged HTML report, and a
  [published report archive](https://zetyre.github.io/athena-bank-playwright-tests/)
- Found and reported two real defects in the app under test, including a race condition in concurrent transfers
